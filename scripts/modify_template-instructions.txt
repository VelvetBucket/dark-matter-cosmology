Run the script by providing:

1. The path to the MadGraph template_files directory.
2. The path to the odd_particles.txt file generated by the dark-sector setup script.

Example:

./modify_template.sh MG5_aMC_v3_6_7/madgraph/iolibs/template_files/ dark-matter-cosmology/build/input/odd_particles.txt

The script will:

- Read the dark-sector particle information from odd_particles.txt.
- Rename the original template_files directory to template_filesOG.
- Create a new template_files directory as a copy of template_filesOG.
- Apply all required modifications only to the new template_files.
- Add the dark-sector masses and degrees of freedom defined in odd_particles.txt.
- Keep template_filesOG unchanged as a backup of the original files.

The odd_particles.txt file is expected to contain the Z2-odd dark-sector particle information generated by the setup script, for example:

# particle    antiparticle    mass    dof
N1            N1              MN1     2
N2            N2              MN2     2
N3            N3              MN3     2
etI           etI             MetI    1
etR           etR             MetR    1
etp           etpc            Metp    2

After execution:

MG5_aMC_v3_6_7/madgraph/iolibs/
├── template_files/      # modified files
└── template_filesOG/    # original files

If template_filesOG already exists, the script will stop without modifying anything :)
